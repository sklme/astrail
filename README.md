# Astrail

Chart the working trail for every agent.

Astrail organizes repositories, environments, context, and reusable skills into a shared workspace for AI agents.

## Project status

This public repository is being prepared for its first source and package release. The repository and resource hosting are initialized; the application source and npm packages have not been synchronized here yet.

## Public resources

[Resource service](https://sklme.github.io/astrail/) · [Schema catalog](https://sklme.github.io/astrail/schema/index.json) · [Template catalog](https://sklme.github.io/astrail/templates/index.json) · [Shared configuration catalog](https://sklme.github.io/astrail/configs/index.json)

The catalogs are initially empty. Versioned resources will be added with public releases. Existing versioned files will remain available with their original contents.
