# astrail-target-codex

Projects the Astrail workspace model into Codex guidance and built-in Skills, with ownership and drift checks. Configuration setup Skills are kept separate from daily Skills and handed off explicitly by bootstrap.

From 0.11.0, documentation and task-record conventions are no longer bundled. Choose your own workflow Skill through shared configuration. Synchronization retires the registered `astrail-records` entry and its default guidance, preserves business documents, and reports modified legacy entries for reconciliation.
