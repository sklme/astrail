# astrail-schema

Versioned JSON Schemas, generated TypeScript types, and a machine-readable `resources.json` catalog. Configuration protocol versions are independent from npm versions.

Exports include `astrail-schema/workspace-v1alpha1.json`, `local-v1alpha1.json`, `config-v1alpha1.json`, and `lock-v1alpha1.json`. Runtime validators load the packaged files without a network request.
