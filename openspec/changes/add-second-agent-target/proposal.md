## Why

Astrail is intended to be agent-neutral, but 0.1 only proves the Codex projection. A second real target is needed before extracting a shared Adapter contract so the abstraction follows demonstrated behavior.

## What Changes

- Select one additional coding-agent product through a compatibility spike.
- Implement its native instructions and capability projection from the Astrail resolved model.
- Compare lifecycle, ownership, discovery, and health-check behavior with Codex.
- Extract only the common target contract supported by both implementations.

## Capabilities

### New Capabilities

- `multi-agent-targets`: Project one resolved Astrail Workspace into multiple native agent formats through demonstrated target contracts.

### Modified Capabilities

- None.

## Impact

This change will add a second target package, compatibility fixtures, shared target interfaces where justified, and documentation for selecting or combining targets.
