# Contributing to Astrail

Issues and pull requests are welcome. This repository is currently in its bootstrap phase; source code, development commands, and package release instructions will arrive with the first public synchronization.

Development changes are integrated into the maintained development source and then synchronized into this public repository. Accepted contributions retain their attribution. Each public version will identify its public source commit and describe its changes.

Use an issue to report a reproducible problem or propose a feature. Remove credentials, private endpoints, and personal data from examples and logs.

## Resource maintenance

`public-resources/` contains the static files deployed to GitHub Pages. `.github/workflows/pages.yml` deploys this directory when it changes on `main`, and supports manual deployment.

Do not overwrite or remove published versioned resources. New versions receive new paths; stable catalog entries are advanced after verification. Prerelease resources do not advance stable entries.
